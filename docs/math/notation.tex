\section{Notation}

\subsection{Discrete Time and Windows}

Let the aligned main timeline be indexed by $t \in \mathbb{Z}$ with sampling interval $\Delta t$.
In the current implementation, $\Delta t = 0.01\,\mathrm{s}$, corresponding to a $100\,\mathrm{Hz}$ main axis.

We use:
\begin{itemize}
  \item $L$: history window length,
  \item $H$: prediction horizon length.
\end{itemize}

\subsection{Control, Observation, and Supervision}

At time $t$, the control input is denoted by
\begin{equation}
\bu_t \in \mathbb{R}^{8},
\end{equation}
corresponding to the eight PWM-related thruster command channels.

The aligned observation feature vector is denoted by
\begin{equation}
\bz_t \in \mathbb{R}^{D_{\mathrm{in}}},
\end{equation}
where the current baseline uses $D_{\mathrm{in}} = 25$ and collects PWM, IMU, velocity-state, and Power features.

The supervised prediction target is denoted by
\begin{equation}
\by_t \in \mathbb{R}^{D_{\mathrm{out}}},
\end{equation}
where the current baseline uses $D_{\mathrm{out}} = 9$ and groups acceleration, angular-rate, and velocity-state terms.

The history input to the model is
\begin{equation}
\bX_t =
\begin{bmatrix}
\bz_{t-L+1} \\
\vdots \\
\bz_t
\end{bmatrix}
\in \mathbb{R}^{L \times D_{\mathrm{in}}}.
\end{equation}

The future target window is
\begin{equation}
\bY_{t+1:t+H} =
\begin{bmatrix}
\by_{t+1} \\
\vdots \\
\by_{t+H}
\end{bmatrix}
\in \mathbb{R}^{H \times D_{\mathrm{out}}}.
\end{equation}

\subsection{Prediction Outputs}

The model predicts
\begin{equation}
\Delta \hat{\bY}_{t+1:t+H} \in \mathbb{R}^{H \times D_{\mathrm{out}}},
\end{equation}
as well as diagonal log-variance terms
\begin{equation}
\log \hat{\bm{\sigma}}^2_{t+1:t+H} \in \mathbb{R}^{H \times D_{\mathrm{out}}}.
\end{equation}

Rollout uses the last available state proxy $\by_t$ as initial condition and reconstructs future states from cumulative increments.
